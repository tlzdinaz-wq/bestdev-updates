# Tablettes 3D (`tablet3d.css` + `tablet3d.js`)

Châssis « appareil » commun à toutes les tablettes de l'interface React
(MDT police / DOJ / gouvernement / SAMS, tablette faction & territoires, patron,
Dynasty 8, DVM, tablettes staff, Weazel, LifeInvader). Chargé par
`interface/build/index.html` après le CSS principal ; le script repère les écrans
de tablette et ajoute autour un châssis, une vitre et un fond, avec une
inclinaison qui suit la souris.

Fichiers livrés minifiés ; les versions lisibles ne font pas partie de la base
distribuée.
