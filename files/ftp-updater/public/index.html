Mise à jour Best Dev

Applique les mises à jour directement sur votre hébergeur, par FTP, FTPS ou SFTP.

Accès à l'hébergeur

Le dossier du serveur est celui qui contient resources/ et server.cfg. Laissez vide si c'est la racine de votre accès FTP.

Après une connexion réussie, les paramètres seront sauvegardés. Le mot de passe n'est jamais enregistré.

Déroulement

Testez d'abord la connexion : l'outil lira la version installée sur l'hébergeur et la comparera à la dernière version publiée. Rien n'est envoyé tant que vous n'avez pas cliqué sur « Mettre à jour ».

Si vous cochez « Mémoriser », seuls le protocole, l'hôte, le port, l'utilisateur et le dossier sont conservés dans ce navigateur. Le mot de passe reste uniquement en mémoire le temps de l'opération.
